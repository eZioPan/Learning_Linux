= 压缩

对数据的可选压缩式 OpenPGP 的一个可组合功能。OpenPGP 中的压缩机制对于应用来说可以是很方便的。

在一个特定的情况下，该功能是特别有用的：当加密一个信息的时候，加密后的输出从定义上来说就是高熵的，是不能更一进步地压缩的——即便明文信息是低熵地，可以被很好地压缩的（比如文本文件）。

这意味着若要使用任何可能的压缩，信息都必须在加密__之前__进行压缩。OpenPGP 提供了一种内置的压缩机制，简化了该流程（否则，信息需要在加解之前和解密之后进行压缩和解压，以达到相同的空间利用率）。

== 解压过程产生一个“封装的”OpenPGP 包流

OpenPGP 中的压缩是一个简单的机制：一个link:https://www.ietf.org/archive/id/draft-ietf-openpgp-crypto-refresh-12.html#name-compressed-data-packet-type[压缩数据包（Compressed Data packet）]作为一系列 OpenPGP 包的压缩容器。

压缩数据包包含了压缩算法的规格，跟随所包含数据的压缩后表示。

压缩数据包中的 OpenPGP 包串可以像处理任何 OpenPGP 包流一样处理。
